# 출근도장 (chulgeun-dojang)

어르신이 안드로이드 폰으로 **출근일·메모를 기록**하고, **월별 근무일지를 사진/PDF로 보내** 일급을 청구하기 위한 초경량 웹앱(PWA)입니다.

- 앱 주소: `https://<GitHub 사용자명>.github.io/chulgeun-dojang/`
- 인터넷이 없어도 기록됩니다 (폰 안에 저장).
- 새 버전이 나오면 다음에 앱을 열 때 자동으로 바뀝니다. 다시 설치할 필요 없습니다.

---

## 1. 폰에 설치하기 (어르신 폰, 한 번만)

1. 폰에서 **크롬(Chrome)** 을 엽니다.
2. 위 앱 주소를 엽니다. (카카오톡으로 링크를 보내 드리고 → 링크 길게 누르기 → **"Chrome으로 열기"**)
3. 오른쪽 위 **︙ (점 세 개)** 를 누릅니다.
4. **"홈 화면에 추가"** 또는 **"앱 설치"** 를 누르고 → **"설치"/"추가"** 를 누릅니다.
5. 홈 화면에 초록색 **✓ 도장 아이콘 "출근도장"** 이 생깁니다. 이제부터는 이 아이콘으로 여세요.

> "출처를 알 수 없는 앱" 설정은 필요 없습니다.

## 2. 사용법 (어르신용)

| 하고 싶은 일 | 누르는 곳 |
|---|---|
| 오늘 출근 기록 | 첫 화면의 큰 초록 버튼 **"오늘 출근 도장 찍기"** |
| 잘못 찍었을 때 | 아래에 뜨는 **[되돌리기]**, 또는 버튼을 다시 눌러 **"네, 지울게요"** |
| 연장·야간·추가근무 | **[메모 · 연장 쓰기]** → 해당 줄의 **[+]** 를 누를 때마다 30분씩 → **[닫기]** |
| 반나절 근무 | 날짜 상세에서 **[출근함]** → **[반나절]** (월 합계에 0.5일) |
| 메모 | 날짜 상세의 메모 칸에 쓰거나 **+조퇴 +지각** 버튼 |
| 한 달 정리 메모 | **[달력 보기]** 맨 아래 **"9월 정리 메모"** 칸 |
| 지난 날짜 고치기 | **[달력 보기]** → 날짜 누르기 → **[출근함]/[안 함]** → **[닫기]** |
| 한 달 근무일지 보내기 | **[보내기]** → **[사진으로 보내기]** → **카카오톡** 선택 |
| 글자 크게 | **[설정]** → 글자 크기 **크게 / 아주 크게** |

- 저장 버튼이 없습니다. 누르거나 닫으면 **자동 저장**되고 "저장됐어요 ✓"가 잠깐 뜹니다.
- 출근 안 한 날에 메모를 쓰면 **"이 날 출근하셨나요?"** 라고 한 번 묻습니다. 어느 쪽을 눌러도 메모는 저장됩니다.
- "N일차"는 그 달에 출근한 날을 순서대로 센 숫자입니다 (예전 엑셀의 A열과 같음). 반나절 근무한 날도 1씩 셉니다.
- 월 합계는 **근무 21.5일 · 연장 3시간** 처럼 자동 계산되어 달력과 근무일지 사진에 나옵니다.

## 3. 데이터 백업 (보호자용) — 꼭 해 두세요

기록은 폰의 크롬 안에 저장됩니다. **크롬에서 "사이트 데이터 삭제"를 하거나 폰을 바꾸면 사라질 수 있으니** 아래 둘 중 하나는 해 두세요.

### 방법 A. 구글 시트 자동 백업 (추천)

입력할 때마다 구글 시트 `records` 시트에 자동으로 올라가고, 보호자가 시트에서 고친 내용도 앱에 반영됩니다. 앱에서 구글 로그인은 필요 없습니다.

1. 구글 시트를 하나 만들거나 기존 시트를 엽니다.
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 전부 복사해 붙여넣고 저장합니다.
4. 왼쪽 **⚙️ 프로젝트 설정 → 스크립트 속성 → 스크립트 속성 추가**
   - 속성: `SYNC_TOKEN`
   - 값: 아무 비밀 문자열 (예: `dojang-7f3k9q`) — 남이 짐작하기 어렵게
5. 편집기 위쪽 함수 목록에서 **`setup`** 을 골라 **▶ 실행** → 권한 허용. `records` 시트가 생깁니다.
6. **배포 → 새 배포 → 유형 선택(⚙️) → 웹 앱**
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사
7. 어르신 폰의 앱에서 **[설정] → 구글 시트 백업** 에
   - Apps Script 웹앱 주소: 6번의 URL
   - 비밀값: 4번의 `SYNC_TOKEN` 값
   을 넣고 **[지금 백업하기]** → "백업을 마쳤어요 ✓" 가 나오면 끝입니다.

동작 방식
- 기록은 먼저 폰에 저장되고, 인터넷이 되면 3초 뒤 시트로 올라갑니다. 실패해도 조용히 다음 기회(앱 실행, 인터넷 복귀)에 다시 시도합니다.
- 앱을 열 때 시트 내용을 받아와 **더 최근에 고친 쪽**을 남깁니다.
- 시트에서 직접 고치면 `onEdit`가 `updatedAt`을 갱신해 앱에 반영됩니다.
- `records` 시트 열: `date | worked(TRUE/FALSE) | memo | updatedAt | amount(하루 1, 반나절 0.5) | overtime(연장) | night(야간) | extra(추가근무)`
- `months` 시트 열: `month(2026-09) | memo | updatedAt` — 월별 정리 메모

#### Code.gs를 새 버전으로 바꿀 때 (URL 유지)
1. Apps Script 편집기에서 **Ctrl+A → Delete** 로 비우고, [원본 코드](https://raw.githubusercontent.com/khn3138/chulgeun-dojang/main/apps-script/Code.gs)를 **Ctrl+Shift+V** 로 붙여넣고 저장
2. 함수 목록에서 **`setup`** 실행 (새 열·`months` 시트 추가)
3. **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** — "새 배포"를 누르면 URL이 바뀌니 주의
- 출근·메모를 모두 지운 날은 시트에 `FALSE`, 빈 메모로 남습니다.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전** 으로 다시 배포해야 반영됩니다 (URL은 그대로).

#### (선택) 보호자용 월별 요약 시트
새 시트 `월별요약`을 만들고 A1 셀에 아래 수식을 넣으면 월별 근무일·연장 시간 합계가 나옵니다.
```
=QUERY({ARRAYFORMULA(LEFT(records!A2:A,7)), records!E2:F}, "select Col1, sum(Col2), sum(Col3) where Col1 <> '' group by Col1 label Col1 '월', sum(Col2) '근무일', sum(Col3) '연장'", 0)
```

#### (선택) 기존 엑셀 데이터 옮기기
예전 월별 탭을 이 구글 시트 파일로 복사(탭 우클릭 → 복사 대상 → 기존 스프레드시트)한 뒤, Apps Script 편집기에서 **`migrateLegacy`** 를 한 번 실행하세요. 실행 로그에 "옮긴 기록: N일, 월 정리 메모: M개월"이 나옵니다.

- 기대하는 형식: **1~31행 = 1~31일, A열 = 일차 숫자(출근 안 한 날은 빈칸), B열 = 메모, 32행부터 = 그 달 정리 메모**
- 탭 이름: `9월`(올해로 처리), `2025년 12월`, `2026-09` 등. **작년 탭은 연도를 넣어 이름을 바꾸세요.**
- 메모의 `반차`/`반나절` → 반나절, `연장 1시간`/`야간 2`/`추가근무 30분` → 근무 시간으로도 옮깁니다 (메모 글자는 그대로 남음). 숫자 없이 `연장`만 적힌 날은 시간을 알 수 없어 메모로만 옮겨집니다.
- 이미 있는 날짜·월은 덮어쓰지 않으니 여러 번 실행해도 안전합니다. 형식이 다르면 `Code.gs`의 `LEGACY_*` 값을 고치세요.

### 방법 B. 백업 파일 (시트 없이)

**[설정] → 백업 파일 만들기** 로 `.json` 파일을 저장해 두고, 새 폰에서 **백업 파일 가져오기** 로 불러옵니다. 날짜별로 더 최근 기록이 남습니다.

## 4. 개발

```bash
npm install
npm run dev        # http://localhost:5173/chulgeun-dojang/
npm test           # Vitest (날짜·일차 계산, 병합, 저장소)
npm run build      # dist/ 생성 (타입 검사 포함)
```

- 스택: Vite + React + TypeScript, vite-plugin-pwa(autoUpdate), Dexie(IndexedDB), html-to-image, jsPDF, date-fns
- 날짜는 항상 로컬 시간 `'YYYY-MM-DD'` 문자열. `toISOString()` 금지 (UTC로 날짜가 밀림).
- html-to-image / jsPDF는 [보내기] 때만 불러옵니다 (첫 화면 번들은 gzip 약 125KB).

```
.github/workflows/deploy.yml  main 푸시 → 테스트·빌드 → GitHub Pages 배포
apps-script/Code.gs           구글 시트 백엔드 (doGet/doPost/onEdit/migrateLegacy)
public/icons/                 PWA 아이콘
src/db/                       Dexie 스키마, records/settings 저장소
src/sync/                     시트 동기화 (pull, push, merge)
src/lib/                      날짜·일차 계산, 메모 규칙, 백업, 내보내기(png/pdf)
src/screens/                  Home, Calendar, DaySheet, Export, Settings
src/components/               BigButton, Toast, ConfirmDialog, MonthNav
```

### 배포 설정 (한 번만)
GitHub 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions** 로 설정한 뒤 `main`에 푸시하면 자동 배포됩니다.
